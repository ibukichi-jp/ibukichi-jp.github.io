# 愛犬写真アセット (Dog Photos)

ダッシュボードの「愛犬たちとの日々」カードに表示する写真ファイルをここに配置してください。

## ファイル名と対応カード
- **`ibuki.jpg`** (または `ibuki.png`): いぶきのカード右側に表示されます 🐶
- **`iroha.jpg`** (または `iroha.png`): いろはのカード右側に表示されます 🐾

## 推奨仕様
- **形式**: JPG, PNG, WebP
- **比率**: 正方形（1:1）推奨（円形にトリミングして表示されます）
- **解像度**: 200x200px 〜 400x400px 程度（自動で美しくフィットします）
